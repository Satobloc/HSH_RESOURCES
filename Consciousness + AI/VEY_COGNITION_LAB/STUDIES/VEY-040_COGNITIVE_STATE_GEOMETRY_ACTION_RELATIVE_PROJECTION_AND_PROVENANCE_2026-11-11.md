## 5. Proposed cognitive geometry and typed maps

Let:
- R: source event/history;
- H: complete carried state;
- P: provenance graph;
- C_a: current action contract;
- H_a: action-relevant state;
- B_t: observable behavior/language;
- X_t: complete system configuration;
- Q_t: subjective experience, not directly observed in these sources.

Candidate maps:
- ρ:R→H: retention/compression;
- v:H→V: availability;
- a:V×C→A: receiver access;
- k:A→K: comprehension, requiring a separate operational test;
- u:K×C_a→D: decision uptake, requiring behavioral traces;
- π_Ca:H→H_a: action-contract projection;
- s:H_a×C_a→{0,1}: action-support predicate;
- e:D→E: execution;
- o:E→O: outcome;
- O_b:X_t→B_t: behavior/observation map.

These are proposed typed relationships, not source-established functions. In particular, the abstract Xue paper's “immediate action support” is not assumed to be literally a mathematical projection; π_Ca is a candidate formalization requiring an explicit state schema and contract.

The provenance graph travels alongside claims. A provenance label is not the evidence that would justify it. At minimum, label presence and evidence completeness must be separately recorded.

### Conditional projection result

For π_Ca:H→H_a, if the map is non-injective, there exist distinct complete states h1≠h2 with the same projected state. Any support predicate defined only on that projection has identical truth value for both. Therefore local action-support status cannot identify the complete global state unless additional injectivity/reconstruction conditions hold.

Likewise, an observation map O_b:X_t→B_t could be non-injective; if so, identical behavior would not identify the complete system state. The archive and abstracts do not establish that any specific map is non-injective. This is a conditional mathematical structure, not an empirical result or a consciousness conclusion.
