# H(s)H Public Front Page — Curated Visual Package
Date: 2026-09-10

Purpose
-------
This package is a curated subset of the images supplied in-chat for the new public-facing
Satobloc/HsH repository. No new explanatory graphics are included. The generated
θ₄/helix infographic from the conversation is deliberately excluded.

Editorial principle
-------------------
The root README should be visual-first: geometry before exposition. The images are divided into:

FRONT_PAGE
  12 images selected to carry the main visual argument.

VISUAL_ATLAS
  Supplemental explanatory/analytical figures that are useful deeper in the repo.

PROVENANCE
  Historical notebook/documentary images. These should be presented explicitly as dated
  historical material, not redrawn into a modern style.

Suggested front-page sequence
-----------------------------
01. Unified Geometric Vision
    Opening broad claim: multiple familiar physical descriptions as consequences/readouts
    of one geometric construction.

02. Particle Spectrum from Geometry
    Photon → electron → quark as increasing structural/topological complexity.

03. Helix / Time-Plane Intersection
    Establish the basic trajectory-and-section picture.

04. θ₄ Tangent / Time-Normal
    Attach the key angular variable directly to the geometry it measures.

05. Recursive Helix on Curved Carrier
    Prevent the reader from reducing the model to a simple straight helix.

06. QCD / Geometric Braiding
    Interaction grammar as braid/interweave structure.

07. Multifilament Bundle into Curved Surface
    Bridge braid structure, finite carrier geometry, and projection/readout.

08. Worldline / Time-Slice Evolution
    Show how time-slice patterns evolve along one propagating worldline construction.

09. Geometric Cosmology
    Make clear that the construction is intended to close at cosmological scale.

10. Lithium / Dark-Matter Geometric-Time Plate
    Example of a phenomenological/cosmological application.

11. Spacetime-to-String-Vibrations Unified View
    Broad cross-scale visual synthesis; best used below the core mechanics, not as the hero.

12. Interaction Resistance / Coil Deformation
    Mechanical response / deformation vocabulary; likely near the transition to current H(s)H.

Root-page recommendation
------------------------
Do not place all 12 at full width. Use roughly 8–10 on the README itself and link the rest
into the Visual Atlas. A likely root set is 01, 02, 03, 04, 05, 06, 08, 09, plus one
worldtube/bundle image. The final choice should be made while writing the README so image
density and text rhythm can be judged together.

Provenance recommendation
-------------------------
Include a small historical strip near the bottom of the root README: an early sketch/notecard,
a 2025 notebook page, and the April 25, 2025 notebook spread. Link each image to the old
Archive visuals/original-source location rather than treating the HsH repo copy as the
primary source.

Linking plan
------------
After this ZIP is uploaded to Satobloc/HsH, the README should:
1. display the curated HsH copies for fast loading and stable layout;
2. make each displayed image clickable;
3. point the click target to the corresponding original image/source in the old Archive
   visuals directory whenever that mapping is available;
4. label historical images with dates/status;
5. avoid implying that conceptual-art images are analytical results.

Notes
-----
- The distinct styles are intentional: polished explanatory plate, computational figure,
  and historical notebook image should remain visibly different.
- Do not homogenize all images into a single glossy aesthetic.
- No newly generated θ₄ infographic is included.
