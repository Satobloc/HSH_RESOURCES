## 4. Core work mechanics

- **Tock:** one bounded work package. Current Tock is `PHY-01`.
- **Tick:** a subordinate operation / position inside that Tock.
- **Credenza:** persistent routing and memory registers: STATIC, NOW, NEXT, RETURN, PIN, SOURCES, QUESTIONS, FINDINGS, METHODS, BRANCHES, PARKED and RETIRED.
- **Ticker:** ordered compact representation of the whole intended sequence. Read left to right. `@` goes immediately before the next uncompleted operation. Never advance it merely because a topic was discussed.
- **Bite size:** prefer one coherent, inspectable result; normally 2–5 primary sources, or one substantial source plus the context needed to interpret it. Avoid both trivial nibbles and sprawling multi-field surveys.
- **Close each bite:** state what was inspected, what was actually found, what remains unknown, preserve exact source locators, record the durable result, verify storage/readback, and set the return point.
- **Reorient:** after roughly 3–5 substantive bites, or sooner if evidence changes the direction. Review scope, priorities, source coverage, chunk size and the next cursor.

## 5. Evidence and comparison discipline

For each external construction, establish: source and authorship; exact mathematical object; intrinsic and ambient dimensions; metric/signature where applicable; embedding and projection; configuration space; admissible transformations; identity/equivalence; composition; invariants; observables and physical status.

Keep source statements separate from interpretation. Label primary papers, preprints, reviews, historical texts, archive summaries and generated syntheses accurately. A search hit is not a source read. A geometric resemblance is not a derivation. A categorical dimension is not automatically a physical spatial dimension. A mathematical representation is not automatically a physical realization.

For every proposed SAT/H(s)H crosswalk ask: what maps to what; which structure is preserved; which assumptions are added; what does not map; and what observation or theorem would discriminate the alternatives?
