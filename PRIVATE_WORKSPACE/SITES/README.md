# Sites — Private LLM Workshop

Status: active private adjunct to the main Sites workspace.

This folder is the **private Sites-specific LLM workshop** inside the private HSH_RESOURCES repository.

It is **not** the main Sites workspace.

The main Sites workspace remains the Glass Sausage Factory. That is the primary place for ordinary Sites planning, priorities, current site-development decisions, and the overall Sites workstream. This private workshop exists only for material that should stay off that main surface for now.

## What belongs here

- private Sites handoff notes;
- source-sensitive or contributor-sensitive questions;
- experimental page/build variants;
- implementation feedback that is useful to another LLM but not ready for the main Sites workspace;
- private reconstruction/Sites interface notes;
- provisional site packets and alternate versions;
- private editorial questions and replies;
- small module/UI experiments that may later be promoted.

## What does not belong here by default

- the main Sites priority list;
- ordinary current Sites planning;
- general site architecture that is already appropriate for the Glass Sausage Factory workspace;
- durable public-facing documentation;
- material that belongs more naturally in another private LLM workspace such as `PRIVATE_WORKSPACE/MAG_RECON/`.

## Relationship to the main Sites workspace

Use this folder as a **private side-channel / back room** for Sites work.

Useful loop:

`main Glass Sausage Factory Sites workspace -> private question/experiment here -> LLM review / source work -> note or packet back to main Sites workspace`

The Glass Sausage Factory remains the control surface. This folder should not grow into a competing second Sites headquarters.

## FLC

FLC-specific reconstruction/editorial experiments belong primarily in `PRIVATE_WORKSPACE/MAG_RECON/`. This Sites workshop may still hold Sites-facing handoffs, packets, or feedback about FLC when the purpose is specifically communication with the Sites worker.

Current examples already here include FLC notes/handoff/site-packet material; those are appropriate because they are Sites-facing communication artifacts.

## Promotion rule

When a private Sites note or experiment becomes ordinary current Sites work, move or restate the useful result in the main Glass Sausage Factory Sites workspace rather than leaving the private workshop as the only source of truth.
