A.3. Gauss Markov interpolation – some examples 
 
 
Let me post some old calculated examples of using the Gauss Markov interpolator 
in various circumstances. The first example is a Harvard Open Ocean model section of 
the Gulf Stream. We look at the soundspeed contours at some depth (which doesn’t so 
much matter for now), and get the solid line result from the model. Now, if we remove all 
the grid points of the model except for the ones with asterisks (a drastic decimation of the 
data), we want to retrieve an “interpolated” version of the Gulf Stream SSP using a Gauss 
Markov interpolation. Using the data-data correlation function, we were able to get the 
dashed line result – a very good match to the original 3D field!
