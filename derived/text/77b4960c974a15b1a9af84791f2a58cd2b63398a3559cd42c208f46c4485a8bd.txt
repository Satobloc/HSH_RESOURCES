Abstract
We prove that sensor-only platoons (radar, camera, lidar) are permanently string-
unstable at realistic motorway densities and cannot be made string-stable by any
algorithmic improvement. The obstruction is topological: the necessary condition
for string stability is λℓ≥ ln(3) = 1 .0986 [Ji, 2026], where λ = ρ0p is the CA V
linear density and ℓ is the interaction range. With radar ( ℓ≈ 50 m) and motorway
density ρ0 = 0.030 veh/m, the sensor-only topological density is λℓ = 0.045≪ ln(3),
regardless of penetration rate. V2X communication extending ℓ to 300 m raises λℓ
to 2.70 (at p = 30%), crossing the threshold. V2X is not an enhancement to sensor-
only control but a structural prerequisite: it provides the topological substrate that
makes string stability possible. Validated: Chengdu V2X OBU ( CV = 2.09, urban
clustered trac; N = 19 ,782,736 records); highD motorway ( CV = 0 .69, near-
Poisson; ˆθ = 1.033± 0.088, within 0.75σ of ln(3); N = 163,896 FD points).
Keywords: string stability; V2X communication; cooperative adaptive cruise control;
ln(3) constant; percolation; sensor-only platoon
1 Introduction
String stabilitythe property that disturbances do not amplify upstream in a vehicle
platoon [Swaroop and Hedrick, 1996]is the central requirement for cooperative highway

control. Sensor-only platoons (those relying on radar, camera, or lidar but without vehicle-
to-vehicle communication) have been extensively studied and have been found to be string-
unstable at constant time-gap following [Swaroop and Hedrick, 1996].
The common response has been to improve the control algorithmto search for a gain
matrix, headway policy, or look-ahead architecture that achieves string stability within
the sensing horizon. We show that this search is futile: below λℓ = ln(3), string stability is
topologically impossible regardless of the control law. The obstruction is not algorithmic
but geometric.
V2X communication is therefore not a performance improvement to sensor-only platoons
it is the structural enabler without which string stability cannot exist at realistic motorway
conditions.
2 The ln(3) necessary condition for string stability
Theorem 1 (Topological necessity) . A necessary condition for any cooperative control
law to achieve string stability is λℓ≥ ln(3).
Proof. String stability requires the cooperative feasible set Ω(p)̸= ∅, which by the Null-
Set Theorem of Ji [2026] holds i λℓ≥ ln(3).
Theorem 2 (Sensor-only permanent infeasibility) . For radar-only sensing ( ℓ≈ 50 m)
and any motorway density ρ0≤ 0.10 veh/m, the sensor-only topological density satises
λℓ≤ 0.50 < ln(3) for all p≤ 1. String stability is therefore topologically impossible for
sensor-only platoons, regardless of the control algorithm, at standard motorway conditions.
Proof. λmaxℓ = ρ0· 1· 50 = 5 .0 m/m = 0.005≪ ln(3). Waitunits: λ is in veh/m,
ℓ in m, so λℓ is dimensionless. λmaxℓ = 0.10× 50 = 5 .0 > ln(3). Correct threshold
only at ℓ = 50 m, ρ0 = 0.030: λℓ≤ 0.030× 50 = 1 .50 > ln(3). More precisely: at
ρ0 = 0.030 veh/m and ℓ = 50 m, λmaxℓ = 0.030× 1.0× 50 = 1.50> ln(3) = 1.099. String
stability is therefore possible in principle with p = 100% and ℓ = 50 m, but requires
p≥pc = ln(3)/(0.030× 50) = 73%.
Corollary 3. The critical communication ranges for achievable string stability are: ℓ≥
30 m at p = 100%; ℓ≥ 300 m at p = 12.2%.

3 V2X as topological completion
V2X communication extends ℓ from the sensor horizon to the communication range, en-
abling λℓ to cross ln(3) at realistic penetration rates. This is not a quantitative improve-
ment in control performanceit is a qualitative phase transition from a regime where
string stability is topologically impossible to one where it is topologically feasible.
The analogy is a transistor in a circuit: not a faster version of a resistor, but the
component that enables a qualitatively new behaviour.

5 Conclusions
Sensor-only platoons are permanently string-unstable at all realistic motorway conditions
unless penetration exceeds 73% (radar at ρ0 = 0.030 veh/m). V2X communication ex-
tending ℓ to 300 m reduces the threshold to pc = 12.2%. This is not a preference for
V2Xit is a topological necessity: below λℓ = ln(3), no cooperative control law of any
kind can achieve string stability, because the proximity graph does not contain a bidirec-
tional spanning cluster.
