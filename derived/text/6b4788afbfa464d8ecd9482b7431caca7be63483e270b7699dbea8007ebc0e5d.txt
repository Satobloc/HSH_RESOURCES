Abstract
Theshortest common superstring problemis to find the shortest string that contains every string in
a given set as a substring. It is conjectured that the greedy algorithm that repeatedly selects a pair of
strings with maximum overlap and merges them is a 2-approximation algorithm, and this conjecture had
remained open for nearly four decades. In this paper, we disprove this conjecture and show that the
approximation ratio of this algorithm is at least 9/4.
1 Introduction
Theshortest common superstring problem(SCS, or theshortest superstring problem) is the problem of finding
a string of minimum length that contains every input string as a substring. It arises in applications such
as genome assembly [18, 21] and data compression [4, 9], and is also discussed in several textbooks [12, 27].
This problem is NP-hard [9] and APX-hard even over a binary alphabet [26]. Consequently, much of the
research on SCS has focused on approximation algorithms and heuristics. Since Blum et al. [3] gave the first
constant-factor approximation algorithm, the best-known approximation ratio for SCS has been repeatedly
improved for over 30 years [1,5,8,17,23], but the best possible ratio remains unknown.
Thegreedy algorithmfor SCS has been studied for nearly four decades [10,13,24]. It repeatedly chooses
a pair of strings attaining the maximum overlap and merges them until a single output string remains.
Here, anoverlapof two strings is a string that is both a suffix of the first string and a prefix of the second.
This algorithm is extremely simple and runs in linear time [25]. Furthermore, some studies report that the
algorithm performs well in practice [15,22]. However, despite its simplicity, its exact approximation ratio is
unknown.
We can easily see that the approximation ratio of the greedy algorithm is at least 2. Indeed, for the input
set{ab n,b n+1,b nc}, the greedy algorithm may begin by merging abn and bnc under a particular tie-breaking
rule, giving an approximation ratio that approaches 2 asn→∞. Motivated by this lower bound, Tarhio
and Ukkonen [24] conjectured that the greedy algorithm always achieves a 2-approximation, a statement
now known as thegreedy superstring conjecture.
Since its formulation, the greedy superstring conjecture has been studied extensively [4, 5, 14, 19, 20]. In
particular, the conjecture is known to hold when all input strings have length 4 [14]. Also, several other works
have studied various formulations and variants related to the greedy superstring conjecture [11,19,20]. Very
recently, new progress has been made on both sides of the approximation-ratio gap. On the lower-bound
side, Chukhin et al. [6] showed that the approximation ratio of the greedy algorithm is at least 2 even when
all input strings have length 6. On the upper-bound side, the same research group improved the best-known
upper bound on the approximation ratio of the greedy algorithm to 3 [5]. Together, these advances left a
gap between the lower bound of 2 and the upper bound of 3. Although the conjecture had remained open
for nearly four decades, no instance with an approximation ratio strictly greater than 2 was known.

1. If|S|= 1, then output the unique element ofS.

3.2 Proof Outline
Before giving the complete proof, we provide an overview of the proof and explain why this construction
works.
As shown in Lemma 5, all length-kcircular substrings ofU i,V i, andW i are distinct. On the other hand,
each string has some length-(k−1) circular substrings in common with the other strings (Lemma 7). Because
of this structure, the de Bruijn graph [7,16] of orderk−1 constructed from all length-kcircular substrings
has an Eulerian circuit (Lemma 8). We can construct an optimal solution to the SCS instanceS k,t using
such an Eulerian circuit (Theorem 10).
In the lower-bound construction, we first merge the length-kcircular substrings generated from each
Ui,V i, andW i and obtain 3tstrings corresponding toU i,V i, andW i (1≤i≤t). The resulting strings
are length-(m+k−1) circular substrings of the corresponding strings, wheremis the number of circular
substrings merged into a given resulting string. Each resulting string has a length-(k−1) circular substring
as a border (Lemma 2). By carefully selecting the first circular substring in each sequence of merges, we
restrict the pairs of borders with long overlaps (Lemma 12). Because of these restrictions, the remaining
merge operations use shorter overlaps and produce a long output string (Theorem 13).
