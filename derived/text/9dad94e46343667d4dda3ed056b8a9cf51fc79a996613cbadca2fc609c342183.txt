1 Main thread of the algorithm
The full cutting algorithm is quite complicated. However, it contains a main thread that is much simpler,
and many of the complications actually come from the additional structures and conditions that have to
be added to this main thread. In this section, we present the proof in a much simplified scenario, which
basically isolates this main thread. The additions needed in full generality, and the reduction to this
simplified case, will be discussed in Section 1.5.
It is useful to keep in mind the following facts and conventions about molecules:
• We often refer to M′⊆ M as a (sub-)molecule by regarding any bond between M′ and M\M′ as a
free end in M′. Also, once we cut out any elementary component S, we will ignore it for the rest
of the cutting algorithm and consider the molecule M\S only.
• An atom m is a parent (resp. child) of another atom n if m is connected to n by a bond with m
being above (resp. below) n. We say m is a descendant (resp. ancestor) of n if m is obtained by
iteratively taking children (resp. parents) starting from n. Note that this is a monotonic process,
i.e. one cannot get back to the start by iteratively taking parents or iteratively taking children.
• If we cut any atom n as free, then this introduces a bottom fixed end at each parent of n (if exists),
and a top fixed end at each child of n (if exists). Recall also that each atom has at most 2 parents
and at most 2 children.
We start by defining the simplified scenario to be studied in this section.
Definition 1.1. We say M is a simplified 2-layer model, if
(1) M has no O-atoms, and we ignore all the degeneracies;
(2) M is a 2-layer molecule M = MU∪ MD with an “up layer” MU and a “down layer” MD, and no
atom in MD is parent of an atom in MU;
(3) Each of MU and MD is a tree, has no fixed end, and the number of bonds connecting an atom in
MU to an atom in MD, is at least ρ (where ρ is a fixed parameter; in the main nontrivial case we
haveρ≫ 1).
The goal is to cut M into elementary molecules (i.e. {3},{4} and{33} molecules, and{2} molecules
with 2 top or 2 bottom fixed ends), such that
#{33}− 10d· #{4}≥c·ρ, (1.1)
where #{33} is the number of{33} molecules etc., and c is a positive constant.
The proof of (1.1) for simplified 2-layer models, which exhibits the main thread of the full proof,
is further divided into 3 cases, corresponding to toy models I–III defined below (for the purpose of
presentation, we will consider both toy model I and toy model I plus, which is a natural extension of the
former). This classification is based on the following two considerations:
(1) Consider the set of atoms in MU that are connected to two atoms in MD by two bonds. Is this set
big or small relative to ρ?
(2) Consider all the atoms in MU that are connected to at least one atom in MD by at least one bond.
Are they all connected to each other (among themselves, without using the other atoms in MU)?
Or are they separated by other atoms in MU?

The reason for considering these two questions will be clear later. For convenience, throughout this note
we will refer to the atoms in (1) (those in MU that are connected to two atoms in MD) as 2-connections,
and denote their number by # 2conn. We also define the set in (2) (the atoms in MU that are connected
to some atom in MD) by X (note that|X| ≳ρ), and define the number of components of X (as defined
in (2) above) by # comp(X).
The four examples in Figure 1, which are examples of toy models I–III below, exactly correspond
to different cases of two-layer molecules depending on different answers to the above questions. More
precisely, we define a two-layer molecule to be:
• Toy model I : if # 2conn = 0 and X = MU;
• Toy model I plus : if # 2conn = 0 and # comp(X) < (100d)−1·|X| (no 2-connections, X has few
components);
• Toy model II : if # 2conn = 0 and # comp(X) ≥ (100d)−1·| X| (no 2-connections, X has many
components);
• Toy model III : if # 2conn≥ (100d)−1·|X| (many 2-connections).
We split the first toy model case into Toy model I and I plus just to simplify the exposition. Note
also that, the case when 0 < #2conn < (100d)−1·|X| is treated similarly to toy models I–II but with an
extra step of removing 2-connections, see Section 1.5.5. As such, in later subsections, we will focus on
how to treat each toy model by itself.
The plan for this section is as follows. In Section 1.1 we consider the toy model I, whose proof
(Proposition 1.6) involves the core arguments in our algorithm in its simplest form. In Section 1.2 we
consider the toy model I plus, which is an extension of the toy model I, and can be treated in similar

1.1 Toy model I
In this subsection we consider the following (first) toy model:
Definition 1.2. We say M is a toy model I , if it is a simplified 2-layer model as in Definition 1.1, and
that each atom in MU has exactly one bond connected to an atom in MD (i.e. # 2conn = 0 andX = MU).
Definition 1.3. Let MD be part of the simplified 2-layer model as in Definition 1.1 (or any resulting
molecule after a cutting sequence). We define MD to be proper, if it does not contain deg 1 or 2 atoms,
does not contain two adjacent deg 3 atoms, and does not contain two deg 3 atoms which are both adjacent
to the same deg 4 atom, see Figure 2.
If M is a toy model I, we define the following algorithm applied to it:
Definition 1.4 (algorithm for toy model I) . Let M be a toy model I. We define the following cutting
sequence. For an example see Figure 3:
(1) If not all atom in MU have been cut, then choose a lowest atom n∈ MU that has not been cut (i.e.
either n has not child in MU or all its children in MU have been cut).
(2) If n is adjacent to an atom m∈ MD which has deg 3, then cut{n, m} as free and cut m as free from
{n, m} if n has deg 4; otherwise just cut n as free.
(3) If MD contains two adjacent deg 3 atoms (say r and r′), then cut {r, r′} as free; repeat until MD
has no adjacent deg 3 atoms.
(4) If MD contains two degree 3 atoms (say r and r′′) both adjacent to the same deg 4 atom (say r′),
then cut{r, r′, r′′} as free and cut r as free from{r, r′, r′′}; then go to (3)–(4) and repeat, until MD
becomes proper (Definition 1.3).
(5) Go to (1) and choose the next lowest atom n∈ MU that has not been cut, and so on.
(6) Suppose all atoms in MU have been cut. If MD is proper, then cut any deg 3 atom; if not, then go
to (3)–(4) and repeat to remove them, and next cut any deg 3 atom, and so on.
Remark 1.5. In Definition 1.4, we are essentially applying a “naive” algorithm in MU where we simply
cut a lowest atom each time, and a “greedy” algorithm in MD where we exploit a {33} molecule (or a
so-called{343} molecule1 where two deg 3 atoms are adjacent to the same deg 4 atom). As mentioned
above, this is the core idea of our proof, in its bare simplest form. It is a simple special case of the
MAINUD algorithm, which corresponds to the toy model I plus in Section 1.2, see Definition 1.12.

Proposition 1.6. Let M be a toy model I, and we apply the algorithm defined in Definition 1.4. Then
in this process we only obtain elementary molecules, and we have
#{4} = 1, #{33}≥ (|MU|− 1)/5. (1.2)
Since|MU| =|X| ≳ρ≫ 1, this clearly implies (1.1).
Proof. Recall the steps (1)–(6) in Definition 1.4. We divide the proof into 4 parts.
Proof part 1. We first prove that each atom in MU is contained in an elementary component (after
it is cut). By the choices we make in (1) and (5), we know that for each n∈ MU, at the time this n is cut,
it must be a lowest atom that still remains in MU; thus no child of it still remains in MU, hence cutting
n will not introduce any top fixed end in MU (and neither does cutting anything in MD). This means
that MU will not contain any top fixed end throughout the process. Since each n∈ MU either forms a
component by itself (when we cut {n} as free in (2)) or belongs to a {33} molecule (when we cut{n, m}
as free in (2)), it is clear by definition of elementary components that n always belongs to an elementary
component.
Proof part 2. We next prove that each atom in MD is contained in an elementary component. Note
that MD initially is a tree, and will remain a forest in the whole cutting process (cutting an atom will
not create any cycle, but may cause a tree to become a disconnected forest). Now consider each step in
(2) involving n∈ MU, at which time MD must be proper by the construction of our algorithm. Consider
the possible effect of this step on MD (we may assume that n is connected to one atom m∈ MD by a
bond, otherwise cutting n will have no effect on MD), see Figure 4:
(a) If we cut n as free (which means m has deg 4), then when viewed in MD, this step simply turns one
and only one free end at m∈ MD into a fixed end, turning m from deg 4 to deg 3.
(b) If we cut {n, m} as free (which means m has deg 3), then when viewed in MD, this step simply cuts
m, which has deg 3, as free from MD.
Here in (a), we note that m must have deg 4 before cutting n (otherwise m must have deg 3 because MD
is proper, in which case we will cut {n, m} by (2)); also when viewed in MD, the bond between n and m
is initially viewed as a free end at m, and is then turned into a fixed end after cutting n as free, turning
m from deg 4 to deg 3. Likewise m must have deg 3 in (b), and when viewed in MD, cutting{n, m} as
free is equivalent to cutting{m} as free because n has no other bonds connecting to other atoms in MD.
Now, regarding the effects described in (a)–(b), we have the following lemma:
Lemma 1.7. Suppose MD is proper at some point of the algorithm, and becomes non-proper after either
(a) or (b). Then, MD will once more become proper after applying (3)–(4), via cuttings of {33} and
{343} molecules only (with each{343} molecule further cut into a{3} and a{33} molecule), and without
seeing any deg 2 atom . See Figure 5 for an illustration.
Proof. Note that MD is always a forest. We then have the following fact, see Figure 6:
(♡) Suppose we cut S⊆ MD as free, whereS is a connected subset of MD (for example, whenS contains
a single atom, or 2 atoms connected by a bond, or 3 atoms connected by 2 bonds). Then, for each
atom q∈ MD\S that is connected to an atom in S by a (pre-cutting) bond e, the post-cutting
molecule MD\S has exactly one componentXq∋ q, which is in bijection with q (and q is the unique
atom in Xq that is connected to S pre-cutting, via the bond e). When viewed in Xq, the bond e is
viewed as a free end at q before cutting, and is turned into a fixed end after cutting.

The proof of (♡) easily follows from the property of forests. In fact, any q1 and q2 (with corresponding
edges e1 and e2) must belong to different components of MD after cutting S; if not, then (pre-cutting)
they can be connected by a path involving atoms in MD\S, but they can also be connected by a path
with all intermediate atoms being in S (using the bonds e1 and e2 and the connectivity of S by itself),
which then produces a cycle and contradicts the forest assumption. As such, for each q we get a unique
post-cutting component Xq, such that e is the only pre-cutting bond between Xq and S. Clearly, when
viewed in Xq, the effect of cutting S as free is equivalent to turning one and only one free end at q (the
one corresponding to e) into a fixed end.
Now, using (♡), we can prove Lemma 1.7. Note that right before performing (b) at a deg 3 atom m,
any atom in MD adjacent to m must have deg 4 (because MD is proper). Then by (♡), MD will break
into at most 2 components after performing (b), and the effect of (b) when viewed in each component is
equivalent to (a). Therefore, we only need to prove Lemma 1.7 for (a).
Assume now MD becomes non-proper, say a {33} molecule forms, after (a). Let this component be
{r, r′}, where r′ has deg 3 before (a), while r has deg 4 before (a) and is turned into deg 3 after (a).
Then, before (a), any atom in MD adjacent to r or r′ must have deg 4 (see Figure 7) because otherwise
we either have two adjacent deg 3 atoms before (a), or have two deg 3 atoms adjacent to the same deg
4 atom before (a), contradicting properness. Therefore, by ( ♡), we see that cutting the {33} molecule
breaks MD into at most 4 components, and the effect of this cutting when viewed in each component is
again equivalent to (a). We then induct on the size of MD and apply induction hypothesis to each of
these components, to conclude the proof.
Finally, assume MD becomes non-proper, but with no {33} molecule forming, after (a). In this case
there must be a {343} molecule forming, say {r, r′, r′′}, where r′ and r′′ respectively have deg 4 and 3
before (a), and r has deg 4 before (a) and is turned into deg 3 after (a). Then, before (a), any atom
adjacent to r′ or r′′ must have deg 4 (see Figure 7) for the same reason as above thanks to properness.
Moreover, before (a), any atom adjacent to r must also have deg 4, because otherwise we would get
a{33} molecule after (a), contradicting our assumption. Therefore, by ( ♡), we see that cutting the
{343} molecule breaks MD into at most 6 components, and the effect of this cutting when viewed in each
component is again equivalent to (a). We then conclude the proof by the same induction as above. This
completes the proof of Lemma 1.7.
Now, with Lemma 1.7, we can finish part 2 of the proof, i.e. each atom in MD is contained in an
elementary component. In fact, those cut in (2) clearly belong to {33} molecule. Those cut in (3)–(4)
also belong to {33} or{343} (and subsequently{3} or{33}) components by Lemma 1.7. Finally, those
cut in (6) either belong to {3} molecule, or are cut in the process of applying (3)–(4) and thus belong to
{3} or{33} molecules by Lemma 1.7.
Proof part 3. With parts 1 and 2 of the proof, we now know that every component is elementary;
it suffices to calculate #{4} and #{33}. We first show that #{4} = 1. Since the first atom cut in (2) must
have deg 4, it suffices to show that # {4}≤ 1. In fact, for each n∈ MU, at the time n is cut, it must be
the lowest remaining atom in MU, which means any possible child of n in MU must have been cut before,
creating a fixed end at n. Therefore, if n has any child in MU at all before any cutting, then it cannot
have deg 4 when it is cut.
On the other hand, before any cutting, MU can have at most one atom without child in MU (see
Figure 8); if not, say there exist two such atoms n and n′, then consider a path ( n = n0,··· , nj = n′)
between n and n′ within MU (since MU is a tree). Then n1 must be parent of n as n has no child in MU,
and then n2 must be parent of n1 as n1 has a child n∈ MU and another child in MD by Definition 1.2,
and so on. In the end n′ = nj must be parent of nj−1∈ MU, which contradicts the assumption on n′.
This proves #{4} = 1.

1.2 Toy model I plus
In this subsection we extend the toy model I to allow more general connections between MU and MD.
Definition 1.8. We say M is a toy model I plus , if it is a simplified 2-layer model as in Definition 1.1,
and each atom n∈ MU has at most one bond connected to an atom in MD (i.e. # 2conn = 0), and the
number of connected components of X satisfies
#comp(X)≤ (100d)−1·|X|, (1.5)
where X is defined at the beginning of this note. Here, if two atoms in X can only be connected via
atoms in MU\X, then they belong to different components of X.
Let us explain the intuition behind Definition 1.8, in particular the role of (1.5). In the case of toy
model I, we have X = MU which is connected, hence # comp(X) = 1. Moreover, as in part 3 of the proof
of Proposition 1.6, we see that MU has at most one lowest atom (i.e. atom without child in MU; in fact
it is not hard to see that MU must have an “upside down binary tree” shape). This latter fact allows us
to apply a “naive” strategy in MU where we always cut the lowest remaining atom, without producing
too many bad{4} atoms.
6

===== PAGE 7 =====
In the current case, MU may have many lowest atoms, so we cannot always choose and cut a lowest
remaining atom. Instead, we improve the strategy by choosing a lowest remaining deg 3 atom n, and
cutting it and all its descendants (which all have deg 4 when n is chosen). Here we do not consider deg 2
atoms, as they will always be lowest in MU and always have to be cut at top priority. This leads to the
idea of the UP algorithm, see Definition 1.9 below, which is another basic component in our proof.
Note, however, that this UP algorithm cannot be simply combined with the “greedy” algorithm in
MD as in Definition 1.4, because now n may have deg 4 descendants in MU, and this naive attempt
may break the key monotonicity property (see part 1 of the proof of Proposition 1.13) and lead to non-
elementary components. As such, we need to be careful and only apply UP at places in MU which will
not affect MD, i.e. in MU\X. Within X we still need to apply the naive strategy, which may lead to bad
{4} molecules due to X.
We can then see the role of (1.5) and the dichotomy concerning #comp(X); in fact, same as in part 3
of the proof of Proposition 1.6, each component of X can have at most one lowest atom . In the naive
strategy, this leads to bad{4} molecules whose number is comparable to #comp(X). Under the assumption
(1.5), this is negeligible compared to the number of good {33} molecules, which will be comparable to
|X| (i.e. the number of bonds between MU and MD).
With the above intuition, we start by defining the UP algorithm in the toy model case.
Definition 1.9 (The UP algorithm, toy model case) . Let M be any molecule which does not have top
fixed end. Define the following cutting sequence. For an example see Figure 9:
(1) If M has a deg 2 atom, then cut it as free. Repeat until M does not have deg 2 atoms.
(2) Choose a lowest deg 3 atom n that has not bee cut (or a lowest atom if M has no deg 3 atoms).
Let Sn be the set of descendants of n. This n and Sn is fixed until all atoms in Sn have been cut.
(3) Starting from n, each time choose a highest atom m in Sn that has not been cut. If m has deg 3
and has a parent m+ or child m− that also has deg 3, then cut {m, m±} as free; otherwise cut m as
free. Repeat until all atoms in Sn have been cut, then go to (1)–(2) and choose the next n, and so
on.
Remark 1.10. The UP algorithm is a combination of a “global low-to-high” (where each time we select
the lowest remaining deg 3 atom in (2)) and “local high-to-low” procedure (where each time we cut the
highest remaining atom in Sn in (3)). This leads to a key monotonicity property, see Proposition 1.11.
The step (3) in the UP algorithm may seem complicated, we explain it as follows: let m be the highest
remaining atom in Sn, the simple option is to just cut m as free. However, in the case described in (3),
the m± will become deg 2 once m is cut as free; moreover m−∈Sn will be a highest remaining atom in
Sn, and m+̸∈ Sn will occur as a deg 2 atom in (1) once all atoms in Sn have been cut. As such, this
deg 2 atom m± have to be cut at top priority, so instead of cutting {m} we can combine this with the
cutting of m±, which also forms a good {33} molecule{m, m±}. This then leads to the step (3) in the
UP algorithm.
We next prove a key monotonicity property of the UP algorithm and a sufficient condition for it to
produce at least one {33} molecule.
Proposition 1.11. The UP algorithm preserves the following monotonicity property: at any time, any
atom in (M\Sn)∪{n} has no top fixed end, and any atom inSn\{n} has no bottom fixed end. In particular,
applying UP only produces elementary components, and with #{4}≤ 1 if M is connected.
Moreover, assume M is connected and has no deg 2 atom. Then applying UP produces only{4} and
{3} molecules, if and only if M is a tree and has at most one deg 3 atom. Otherwise, applying UP will
produce at least one {33} molecule.

Proof. We divide the proof into 4 parts.
Proof part 1. We first prove the monotonicity property, which implies all components are elementary
(since each atom either forms a component by itself or belongs to a {33} molecule, due to (1)–(3) in
Definition 1.9). Note that initially there is no Sn and M has no top fixed end by assumption, so it suffices
to prove that the monotonicity property is perserved. First, any deg 2 atom n cut in (1) must have two
bottom fixed ends by monotonicity, so it has no child remaining when it is cut, thus cutting it will not
introduce any top fixed end .
Now let n and Sn be as in (2), and m be a highest remaining atom in Sn as in (3). When n is
chosen in (2), all atoms in Sn\{n} must have deg 4 by construction, and thus have no bottom fixed end.
Consider the operation of cutting m as free in (3). We then know that that this cutting does not create
any bottom fixed end inSn\{n} (as m is highest), and does not create any top fixed end in (M\Sn)∪{ n}
(as any child of m must belong to Sn\{n}), see Figure 10. The same holds for the operation of cutting
{m, m±}, because this is equivalent to cutting {m} and then cutting a deg 2 atom (either m+̸∈Sn with
two bottom fixed ends or m−∈ Sn\{n} with two top fixed ends). This proves that the monotonicity
property is perserved, as desired.
Proof part 2. We prove #{4}≤ 1 when M is connected. For this, just note that after the first
cutting, M will always contain an atom that is not deg 4. By construction, this means that the n chosen
in (2) will always be deg 3; moreover, any m∈Sn\{n} that is cut in (3) also cannot be deg 4, because m
has a parent inSn which must have been cut before m thanks to the highest assumption of m. Therefore,
only the first atom can produce a possible {4} molecule, and thus #{4}≤ 1.
Proof part 3. Suppose M is connected and has no deg 2 atom, we prove that either # {33}≥ 1, or
all components are{4} and{3} (with #{4}≤ 1). If not, then we must have a {2} component. Consider
the first atom m that has deg 2 when we cut it, and consider the cutting operation that turns m into deg
2, which must be cutting some deg 3 atom p as free (this p cannot have deg 4, because a degree 4 atom is
cut only when no degree 3 atoms are present, and in this case cutting a degree 4 atom cannot produce a
degree 2 atom). This cutting creates a fixed end at m, so this p must be a parent or child of m; moreover
this m and this p must both be deg 3 at the time of cutting p, but this violates Definition 1.9 (3).
Proof part 4. Finally we prove #{33} = 0 if and only if M is a tree and has at most one deg 3 atom.
For this, consider the increment of the quantity σ := # bo/fr− 3#atom, where # bo/fr is the number of
bonds and free ends (not counting fixed ends) and # atom is the number of remaining atoms. It is easy
to see that cutting each {2} /{3} /{33} /{4} molecule increases σ by 1, 0, 1 and −1 respectively. Since
finally σ = 0, we see that #{4}− (#{2} + #{33}) =σinit (initial value of σ).
Note that initially # bo/fr = #deg− #bond where # deg is the total degree of all atoms (not counting
fixed ends) and # bond is the number of bonds (because each bond contributes twice to the degrees),
so σinit = (|M|− #bond)−| M3| where|M3| is the number of (initially) deg 3 atoms in M. Moreover
by connectedness we have # bond ≥ |M|− 1 with equality if and only if M is a tree, and note also
#{4}∈{ 0, 1} (and #{4} = 1 if and only if |M3| = 0 by the same proof in part 2), it is then easy to see
that #{2} + #{33} = 0 if and only if M is a tree and |M3|≤ 1. This completes the proof.

1.5.1 O-atoms and ov-segments
First, in the real problem, the molecule M may contain O-atoms. This leads to the more involved
definition of cutting operations: now cutting an atom n as free introduces fixed ends not only at adjacent
atoms, but also at atoms which are connected to n by an ov-segment, which is part of a particle line with
all interior atoms being O-atoms. In particular each bond in this ov-segment is broken after cutting n
as free, and a simple pair (formed by a free end and a fixed end) is introduced at each O-atom in this
ov-segment, see Figure 21.
The notion of ov-segments is important in the analysis of O-atoms, and should be viewed as a gener-
alization of edgs/bonds. Using this, we can define the associated notions of being ov-adjacent (connected
by an ov-segment), ov-parents and ov-children, and ov-components (connected components under the
relation of being ov-adjacent), etc. Fortunately, in almost all cases, this generalization does not cause
any essential change to the proof; we simply translate every sentence in the proofs in Sections 1.1–1.4
into the language of ov-segments, with “adjacent” replaced by “ov-adjacent” and “components” replaced
by “ov-components”, etc. As an example, the fact (♡) in the proof of Lemma 1.7 now reads (Figure 22):
(♡♡) Suppose we cut S⊆ M as free, where S is an ov-connected subset of M and M is a tree. Then,
for each atom q∈ M\S that is connected to an atom in S by a (pre-cutting) ov-segment e, the
post-cutting molecule MD has exactly one component Xq corresponding to q. Moreover, when
viewed in Xq, the operation of cutting S turns exactly one free end at q into a fixed end.
There are only two places where extra arguments are needed in addition to this translation, i.e. the
2CONNUP algorithm and the definition of primitivity, which will be explained in the actual proof.

1.5.3 Reducing each layer to a tree: layer refining
In both the toy models in Sections 1.1–1.4 and the layer selection process in Section 1.5.2 above, it is
crucial that each layer of M is a forest. In reality, to deal with the case where M contains cycles within
a single layer, we need to define the layer refining process as follows.
Recall each single layer Mℓ of M contains finitely many C-molecules (i.e. molecules with only C-
atoms) joined by O-atoms, that each C-molecule contains at most Γ = O(1) independent cycles , and
joining these C-molecules by O-atoms does not add any cycle. We have a simple and intuitive lemma,
which states that (see Figure 24):
• For each molecule M with at most Γ independent cycles, we can always divide it into at most Γ + 1
subsets Mj (0≤j≤ Γ), such that each subset is a tree, and no atom in Mi can be parent of atom
in Mj for i<j .
Now, to complete the layer refining process, we simply apply the above lemma to each of the C-molecules
in each layer of M to get, for each 0≤j≤ Γ, a label j subset of each such C-molecule in each layer. We
then combine the label j subsets for all these C-molecules, and distribute the O-atoms appropriately, to
divide each layer Mj into at most Γ + 1 thin layers, such that each thin layer is now a forest. This then
allows us to repeat the layer selection process in Section 1.5.2; the use of thin layers instead of layers
leads to one extra step in layer selection, but this is easily adjusted.
We remark that the above layer refining process does require the total number of independent cycles
in these single-layer C-molecules to be negligible (compared to ρ). When this total number of cycles
is large, we can perform an alternative cutting sequence that exploits these cycles. This requires layer
refining of a subset of layers and also leads to a minor auxiliary notion of primitivity, which we omit here.
1.5.4 Strong and weak degeneracies
In Definition 1.1 we have ignored any degeneracies and assumed that all{33} molecules lead to power gain.
In reality there may be exceptions to this (when the ( xe,ve) for fixed ends e at this{33} molecule takes
some highly specific values), where we cannot gain enough powers of ε from the integration associated
with this{33} molecule. One example is when
|xe1−xe7|≤ ε1−κ, |ve1−ve7|≤ ε1−κ (1.20)
for some small constant κ, where e1 and e7 are the two fixed ends of the {33} molecule.
16

===== PAGE 17 =====
As such, we define a strong degeneracy to be an instance where (1.20) happens at two edges that
would become the two fixed ends if we cut the two atoms as a {33} molecule (in fact a so-called {33A}
molecule, but we ignore this minor point). Similarly we can define the notion of weak degeneracy, which
involves one or two atoms and some conditions similar to (1.20). Note that these definitions only involve
certain edges and atoms in M, and is not a priori associated with any concrete cutting sequence.
Our strategy is such that, when there are many degeneracies, we shall perform an alternative cutting
sequence, where we do not gain from {33} components but instead gain from the extra degeneracy
assumptions such as (1.20). Compared to the sophisticated algorithms exploiting {33} molecules, this
alternative cutting sequence essentially follows the simple procedure where we cut every atom by itself,
so that most of them are cut as {3} molecules. Usually integrating a {3} molecule does not gain any
power, but if this {3} molecule contains an edge or atom that is involved in some degeneracy condition
like (1.20), then it is clear that this{3} molecule integration should gain some power, which effectively
turn this{3} molecule into a good one.
In practice, there will be two places in the overall algorithm where we need to consider degeneracies:
the first time for strong degeneracies, and the second time for weak degeneracies. If there are many (strong
or weak) degeneracies, then we can apply the alternative cutting sequence (with some complications as
described above) to conclude; if there are few (strong and weak) degeneracies, then their effect will be
negligible and we can get rid of them and proceed with the main thread of our algorithm.
1.5.5 Additional ingredients and pre-processing
Finally, we discuss a few minor ingredients that are needed in the full case, that are not discussed in
Sections 1.5.1–1.5.4 above.
Cutting exceptional components. Recall the notion of exceptional components in step (3) in the layer
selection process in Section 1.5.2. When there are no exceptional components, we know that MU =
MℓU∪ M(ℓD:ℓU ) is a forest; however, when there are a (positive) negligible number of such exceptional
components, we need to cut them first, before defining MU which can be a forest. It is easy to show that
this cutting process leads to a negligible number of bad {4} components.
Pre-processing. In Definition 1.1, we have assumed that the 2-layer moleculeM has no fixed ends. This
is the case if the are no exceptional components in layer selection, but if there are exceptional components
that are cut as above, then this will create fixed ends (and thus deg 3 atoms after we subsequently cut
all deg 2 atoms) in both MU and MD. Here, depending on the number of components of deg 3 atoms
in MD (similar to the dichotomy in Sections 1.2–1.3), we either apply the dual of 3COMPUP in MD
similar to Section 1.3, or apply an extra pre-processing step to turn MD into a proper molecule. This
then allows us to execute the main thread algorithm, just as the case of no fixed ends.
Handeling 2-connections. Recall that in the toy models, there is a case when the number of 2-
connections satisfies 0 < #2conn≪|X| (see Section 1.4), which is not covered in any toy model. In this
case we will need to first cut all these 2-connections, so no more 2-connections remain in the resulting
molecule, and then proceed as in either toy models I and I plus or toy model II, depending on the
dichotomy. There will be fixed ends, but they can be handled by pre-processing as above. Finally, this
also leads to some complications as the set X involved in the dichotomy needs to be replaced by some
natural modifications, which will be explained in details in the algorithm MAINUD in the actual proof.
