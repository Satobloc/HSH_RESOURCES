4. N = 4 ⊃ N = 1. 
A 4d N = 4 supersymmetric theory is a special case of a 4d N = 1 supersym­
metric theory. 
a) Describe the ﬁeld content of N = 4 SYM in terms of multiplets of some 
N = 1 subgroup. 
b) Write the N = 4 lagrangian in N = 1 superspace. 
c) Convince yourself that this Lagrangian has SO(6) R-symmetry (e.g. by 
examining the Lagrangian written in components). Is N = 1 supersymmetry 
plus this R-symmetry enough to convince you that this action is actually N = 4 
supersymmetric?
