README
nLab software
The software underlying the nLab is a heavily modified fork of Instiki. However, the code has moved quite far away from the original Instiki and now heavily relies on Python scripts that are called from Ruby.

Installation
We have reverse-engineered installation instructions.

Joining in
All help is very welcome! Get in touch on the nForum.

The codebase is in maintenance mode and not actively developed. We are generally happy to merge pull requests on the user interface as long as:

the users like it (find out on the nForum),
the code changes do not make the codebase more complicated to maintain.
