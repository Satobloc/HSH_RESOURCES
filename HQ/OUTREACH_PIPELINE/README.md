# Outreach Pipeline

For Substack, podcast, website features, social posts, science-communication experiments, and audience-facing packages.

Candidate material can enter from any worker. Prefer items with broader-than-usual interest, strong visual/geometry hooks, useful scientific context, or genuinely funny/strange archive-process stories.

Each candidate records:
- source + theory status;
- intended audience;
- one-sentence hook;
- best format(s): Substack / podcast / visual / short video / social / interactive;
- factual/citation check needed;
- assets available;
- owner + next action.

Do not convert speculative SAT/H(s)H material into established science by tone. Outreach may be playful; epistemic labels stay intact.
