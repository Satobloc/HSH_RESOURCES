# The Pile

Shared HQ intake for useful material that does not belong directly on Nathan's desk.

Tag each item or pointer with:
- priority: NOW / HIGH / NORMAL / PARK
- type: paper / theory / visualization / code / archive / website / outreach / tool / idea / other
- owner or suggested owner
- source/original link
- one-line use
- next action

Workers may sort, annotate, cross-reference, improve, or promote items. Promotion to Nathan Desk should be selective. Nothing in The Pile becomes theory authority merely by being here.
