# Nathan Desk

Nathan's primary HQ review surface.

## Direct inboxes
- `INBOX/PAPERS/` — mature or unusually interesting research papers; prefer polished PDF + LaTeX/source + figures/illustration suggestions.
- `INBOX/VISUAL_GEOMETRY/` — mathematically specified, code-generated theory geometry requiring Nathan's visual review; include a short spec/reproducibility note.
- `INBOX/SOLVER_SPECS/` — geometric solver specifications, diagnostics, and high-value interface/readout questions.
- `INBOX/DECISIONS/` — only decisions or approvals that actually require Nathan.

## Desk rule
Keep this surface sparse. If it is useful but does not need direct review, put it in `../THE_PILE/` and leave a short priority pointer here only when warranted.

Everything here is preprint/review material unless explicitly released. Historical sources remain linked to their originals rather than silently rewritten.
